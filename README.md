# 班主任智慧工作台

一个**单文件、零依赖、可离线**的班主任工作台。

整个应用就是一个 `index.html` —— 不需要安装任何环境、不需要数据库、不依赖任何外部库或 CDN。下载下来双击就能用。

---

## 快速开始

### 方式一：在线使用（推荐）

部署到 GitHub Pages 后，任意设备浏览器打开即可：

```
https://huayanxing.github.io/hyx/
```

> 首次需要在仓库 **Settings → Pages** 中开启：`Source` 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等待 1～2 分钟。

### 方式二：本地文件

把 `index.html` 下载到电脑，双击用浏览器打开即可，**全程离线可用**，不联网也能正常工作。

## 年级成绩分析

面向**初二年级 / 初三年级**两种口径设计（初二无化学、初三有化学）。

| 子页签 | 功能 |
| --- | --- |
| 📊 均分与排名 | 各科均分、各班各科均分矩阵与班级排名；顶部可勾选**不计入总分与排名的科目** |
| 🔀 考试对比 | 两次考试「班级 × 学科」差值矩阵（本次均分 − 上次均分）与差值排行榜 |
| 🎯 优秀率 / 合格率 | 各科优秀线、合格线**可随时调整**，改动即时重算 |
| 📶 分数段统计 | 起始分、步长、段数三参数可调，实时统计各段人数 |
| 👥 成绩名单 | 名单**直接在线编辑**（姓名 / 班级 / 考试号 / 各科分数），可按班级筛选、可搜索 |
| 👩‍🏫 任课教师 | 班级 × 科目教师姓名矩阵，可编辑、可从 Excel 导入 |
| 📥 数据导入 | 支持 `.xlsx`（多工作表可选）/ `.csv` / 直接粘贴表格 |

**关键规则**

- **缺考判定**：任一计入科目没有分数即视为缺考，不计入总分与年级排名。
- **科目开关**：某科不计入总分时，该科既不参与排名，也不算作缺考科目；但该科自身的均分、优秀率、合格率仍照常统计。
- **进步率** = （上次考试年级名次 − 本次考试年级名次）/ 上次考试年级名次。
- **均分口径**：分母为该科**有成绩的人数**（缺考不计入分母），与 Excel 的 `AVERAGEIF` 语义一致。
- **默认分数线**：语数英 117 / 78，历史道法 45 / 30，物理 90 / 60，总分 531 / 354。

## 多设备同步（可选）

**默认是单机模式**：数据存在打开它的那台设备的浏览器里，换电脑打开自然是空的（浏览器按「设备 + 网址」隔离存储）。

想让手机和电脑看到同一份数据，需要一层云端中转。本仓库提供了自建方案：

**Cloudflare Pages + KV**，单文件、零依赖，个人用量在免费额度内。

| 它解决什么 | 说明 |
| --- | --- |
| 跨设备同步 | 打开同一个网址 + 填同样的地址和口令，数据自动互相同步 |
| 冲突处理 | 按分片时间戳判定，谁新听谁的，旧数据不会覆盖新数据 |
| 图片同步 | 聊天截图上传后换取可跨设备访问的地址 |
| 一个网址两个用途 | `https://<项目名>.pages.dev` 既打开网页也提供同步接口，同源、无跨域问题 |
| 隐私 | 数据存在你自己的 Cloudflare 账号下，口令不在网页源码中 |

| 文件 | 说明 |
| --- | --- |
| [`_worker.js`](_worker.js) | **Pages 版后端（推荐）**，放在仓库根目录即可 |
| [`worker/worker.js`](worker/worker.js) | Worker 版后端，逻辑相同，仅在你有自定义域名时才需要 |

> ⚠️ **不要用 `*.workers.dev` 地址。** 该域名在国内被 DNS 污染（会被解析到 Facebook 的 IP），
> 浏览器直连必然失败，工作台会提示「连不上后端」。请用 `*.pages.dev` 或你自己的域名。

部署步骤见 **[worker/README.md](worker/README.md)**。部署完在「设置 → ☁️ 云同步」里填地址和口令即可。

> 说明：工作台页面右上角有同步状态徽标。显示 **「单机模式」** 表示没连云端；显示 **「云端已同步」** 表示正常。
> 没有配置云端时，一切功能照常可用，只是数据不出本机。

## 技术说明

| 项 | 说明 |
| --- | --- |
| 架构 | 单个 HTML 文件，CSS / JavaScript 全部内联 |
| 外部依赖 | **无**。不引用任何 CDN、字体或第三方脚本 |
| 图表 | 全部为**手写内联 SVG**（柱状图、折线图、环形图），断网也能正常显示 |
| 图标 | 全部使用 Emoji / 内联 SVG |
| 数据存储 | 本机 `localStorage`（业务数据）+ 本机 `IndexedDB`（文档中心文件、聊天截图）；可选用自建 Cloudflare Worker 做云端同步 |
| 数据备份 | 设置页支持「导出 JSON 备份 / 导入恢复」；另有每日自动备份 |

**存储位置**

| 用途 | 位置 |
| --- | --- |
| 业务数据 | `localStorage` → 键名 `banzhuren_workbench_data` |
| 文档中心文件 | IndexedDB → 库名 `wb_workbench_files` |
| 聊天截图 | IndexedDB → 库名 `wb_workbench_media` |

> ⚠️ **数据不随代码走。** 数据保存在浏览器的本地存储里，浏览器按「来源（域名 / 文件路径）」隔离存储空间。因此换设备、换浏览器、或从本地文件切到线上网址，都需要通过「导出 JSON 备份 → 导入恢复」手动迁移一次；**或者按上一节配置云同步，让它自动跟随**。

## 兼容性

- Chrome / Edge 等基于 Chromium 的现代浏览器
- 使用 `file://` 协议双击打开时，IndexedDB 同样可用（已验证）
- 若浏览器禁用了 IndexedDB，会自动降级为 base64 存储，功能不受影响

## 隐私提示

- 工作台代码本身**不含学生成绩等真实数据**——真实数据只存在于使用者自己浏览器的本地存储中，不会随代码上传。
- 源码中的「载入示例数据」函数含有**真实学生 / 教师姓名**，本仓库为**公开仓库**，这些姓名会被搜索引擎收录。如需去除，把这几个示例姓名替换成虚拟姓名即可，其余功能不受影响。
